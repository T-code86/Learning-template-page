A FEW GOOD QUESTIONS

Before you
get started.

Do I need experience to get started?

No. The learning path begins with the core building blocks of a web page. You can work through the topics in order and practice as you go.

What will I need?

A computer, a modern web browser, and a code editor are enough to begin. The project examples use standard HTML, CSS, and JavaScript.

Is this a finished course platform?

This project is a front-end learning concept and portfolio piece. It presents a curriculum and project ideas; it does not include accounts, hosted lessons, or a backend.
