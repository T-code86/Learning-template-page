PROJECT 01 / LAYOUT · RESPONSIVE

A digital magazine

Design a landing page for an independent magazine, journal, or local newsletter. Give a featured story a strong point of view and help readers find the next thing to explore.

The brief

Create a responsive editorial homepage with a masthead, navigation, lead story, supporting article cards, and a simple footer. Write original sample headlines and use images you created, licensed, or can clearly credit.

Skills to practice

  • Semantic header, navigation, main, article, and footer elements.
  • Grid or Flexbox for a flexible article layout.
  • Responsive type, image cropping, and intentional whitespace.
  • Accessible image alternatives and clear link labels.
IMAGE DETAIL

The preview is a custom illustration, not a finished website screenshot. Treat its colors and composition as an art direction reference—not a requirement to copy.

PROJECT 02 / LAYOUT · RESPONSIVE

A product landing page

Introduce a fictional product, service, or personal project. Show what it is, who it helps, and the next step you want a visitor to take.

The brief

Build a focused landing page with a navigation bar, a clear value proposition, a product visual, three concise feature descriptions, and one primary call to action. Keep the content honest: if the product is fictional, say so.

Skills to practice

  • Visual hierarchy and readable headline sizing.
  • Reusable color, spacing, and typography values.
  • Responsive layout with CSS Grid or Flexbox.
  • Visible focus states and strong text contrast.
IMAGE DETAIL

The abstract package is an original vector illustration. Replace it with your own SVG, product photo, or CSS artwork and describe what the image adds to the page.

PROJECT 03 / INTERACTION · RESPONSIVE

A personal dashboard

Turn a dashboard into a calm daily check-in: show a few useful metrics, one recent activity view, and a clear path to the most important action.

The brief

Create a small dashboard for a fictional reading list, study routine, or project tracker. Make at least one control work—for example, filter activity, mark a task complete, or switch between views—and explain the result to the user.

Skills to practice

  • Readable interface layout and meaningful data labels.
  • JavaScript events and small, explicit pieces of state.
  • Keyboard-operable buttons and visible focus.
  • Status messages for important updates.
IMAGE DETAIL

The dashboard image is a static design sketch, not a live analytics product. The example bars are decoration, not real data; label sample data if you add it to your implementation.
