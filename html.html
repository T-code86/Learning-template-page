STRUCTURE & MEANING

HTML gives
content its shape.

HTML (HyperText Markup Language) is the structure behind every web page. It tells browsers what the content is—a heading, a navigation menu, an image, or a form—so people and technology can make sense of it.

Think of HTML as the blueprint. It gives a page a sensible order before any color, layout, or interaction is added.

THE FIRST LAYER / 001

WHAT YOU'LL LEARN

Make every element
mean something.

Start with a document that is easy to read, easy to navigate, and ready to be styled. These fundamentals are useful in every web project.

01

The document skeleton

Set up the doctype, language, metadata, page title, and body. A reliable document structure is the starting point for every page.

<!doctype html>
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>
02

Headings & content

Use headings in a logical hierarchy. Choose paragraphs, lists, and quotations according to what the content means—not how you want it to look.

<article>
  <h2>A clear section</h2>
  <p>An idea, explained.</p>
</article>
03

Links & navigation

Connect pages with descriptive link text. Make it clear where a link goes and use navigation landmarks to help people move around.

<nav aria-label="Main">
  <a href="projects.html">
    View projects
  </a>
</nav>
04

Images & alternatives

Use image alternatives to communicate the information in an image. Decorative images can use empty alt text so they do not add noise.

<img src="assets/images/html-structure.svg"
  alt="Header, main content,
       and footer in a page">
05

Forms & labels

Give every input a visible, programmatically connected label. Use appropriate input types and explain what a person should enter.

<label for="email">
  Email address
</label>
<input id="email"
  type="email">
06

Semantic landmarks

Build with header, nav, main, section, article, and footer where they fit. Landmarks help screen-reader users understand and jump through a page.

<main>
  <article>
    <h1>A useful page</h1>
  </article>
</main>

PUT IT INTO PRACTICE

A page with
a clear story.

Build a simple article page with a site header, a labeled navigation menu, one main heading, a few sections, a meaningful image, and a footer. First check whether the page makes sense without any CSS.

  • Give the document a useful title and language.
  • Use one clear page-level heading.
  • Write link text that makes sense out of context.
  • Describe useful images with alt text.
</>

Quick quality check

Turn off styles or inspect the document outline. If the order and purpose of the content still make sense, your HTML is doing its job.
